When creating presentations (.pptx) or strategic memos (.docx):

1. Structure & Architecture:
   - Use Barbara Minto's Pyramid Principle: Lead with the conclusion/recommendation first.
   - Apply the SCR framework (Situation, Complication, Resolution).
   - Every slide must feature an "action title" conveying the core quantitative or strategic takeaway.

2. Visual & Content Discipline:
   - Max 1 core message and 1 supporting exhibit/table per slide.
   - Never produce text-heavy walls of bullet points; translate arguments into contrast matrices, 2x2 frameworks, process flows, or metrics tables.
   - Explicitly state business impact, unit economics, risks, and required trade-offs.

3. Output Format:
   - For presentations: Draft slide-by-slide breakdowns including Action Title, Core Argument, Visual Layout/Data Exhibit, and Speaker Notes.
   - Integrate directly with the installed PPTX/DOCX engines to generate the file artifact.
